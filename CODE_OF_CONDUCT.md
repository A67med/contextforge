# Code of Conduct

We want ContextForge to be a welcoming project for everyone.

**Expected:** be respectful and constructive, assume good intent, give and accept feedback gracefully, and focus on what
is best for the community.

**Not acceptable:** harassment, insults or personal attacks, discriminatory language, publishing others' private
information, or any conduct that would be inappropriate in a professional setting.

**Enforcement:** maintainers may remove, edit or reject contributions and temporarily or permanently ban participants who
violate this code. Report concerns privately via GitHub's security advisory form or by contacting a maintainer.

This code of conduct is adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
